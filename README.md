# Ronova AI Companion

这是一个出于个人兴趣、借助 Codex 制作的若娜瓦桌面 AI 陪伴项目。主要想尝试让角色以文字和语音的方式参与日常交流，再加上一些简单的互动功能。目前还不完善，欢迎感兴趣的朋友体验。

## 当前功能

### 文字聊天与语音交流

通过千问、DeepSeek 等大模型生成回复，再使用 **GPT-SoVITS V2ProPlus** 或 **IndexTTS-2.5** 在本地合成角色语音。两个语音模型及所需运行环境均包含在完整项目包中，可以在设置中切换。

支持文字输入、中文语音识别和连续语音对话，也可以在通话中打断回复、静音或挂断。千问实时模式直接使用云端返回的语音。

语音识别和本地语音合成在电脑上运行，**大模型回复仍需要通过联网调用 API 获取**。

### 角色知识库

为角色整理了一个本地 RAG 知识库。交流时会检索相关的游戏背景资料，再交给大模型作为回答参考，尽量让角色的回答贴合游戏中的设定与经历。

### 记忆与好感度

支持保存和管理交流中的个人信息、偏好与重要事情，方便后续对话承接。还加入了一个简单的好感度系统，让关系随互动产生一些变化，并搭配不同阶段的立绘和誓约功能，增加一点趣味性。

### 主动来电

角色可以结合近期交流内容，在允许的时段内主动来电。可设置开关、来电时段、每日次数和间隔；响铃时不开启麦克风，接听后才开始通话。

## 运行条件

- **系统**：Windows x64。
- **显卡**：支持 CUDA 的 NVIDIA 独立显卡，显存以 **8 GB 或以上**作为运行参考，并安装兼容的显卡驱动。实际显存占用和合成速度会随所选模型及硬件变化。
- **网络与 API Key**：需要联网，并自行前往**千问、DeepSeek 等服务商的官方网站或开放平台**获取 API Key。不同服务商的 Key 不能混用，调用可能产生费用；使用云端音色还需具备对应权限。
- **音频设备**：语音通话需要麦克风，以及扬声器或耳机。
- **磁盘空间**：当前完整项目解压后约 **20 GB**，体积较大。除项目本身外，还需要为环境重建和运行缓存预留额外空间。

完整运行包包含 Python、语音环境、离线依赖和模型，无需另外安装 Python、PyTorch 或 CUDA Toolkit。若系统缺少 Visual C++ 运行库，可使用包内 `runtime/prerequisites` 中的安装程序补齐。

## 启动与操作

### 启动

1. 从 [Releases](https://github.com/LMHaruna/ronova-ai-companion/releases) 下载完整运行包的全部 `.7z.001`、`.7z.002` 等分卷，放在同一文件夹，使用支持 7z 分卷的工具从 `.7z.001` 开始解压。保留解压后的目录结构，不要在压缩包中直接启动。`SHA256SUMS.txt` 提供各分卷的完整性校验值。
2. 双击 `Start-Client.cmd`，等待环境准备和客户端启动。
3. 前往所选模型服务商的官方网站或开放平台获取 API Key，在客户端设置中选择对应模型并填写；按需要检查模型名称和接口地址。
4. 选择麦克风、输出设备及扬声器或耳机模式。

以上步骤适用于包含环境、模型和素材的完整运行包。只下载源码而未取得运行资源时，无法按此方式直接启动。源码中的 `config/realtime-voice.example.json` 是不含个人音色配置的示例；缺少 `config/realtime-voice.json` 时，先复制该示例并命名为 `realtime-voice.json`。

首次启动、移动目录后启动或切换本地语音引擎时，准备过程可能较长。不要删除随包的环境、模型和离线安装包；需要修复环境时可运行 `Setup-Desktop.cmd`。

### 日常操作

- **文字交流**：在聊天页输入内容并发送。
- **语音通话**：在聊天页开始通话，或接听主动来电；通话中可静音或挂断。响铃时不开启麦克风，接通后才开始采集。
- **切换模型与声音**：在设置中选择对话模型；使用本地合成的文字模型可选择 GPT-SoVITS 或 IndexTTS。切换后等待引擎加载完成。
- **管理记忆与关系**：在设置中的“记忆与关系”页面查看和管理记忆及关系状态。
- **设置主动来电**：在设置中调整来电开关、时段、次数和间隔。
- **誓约**：好感度达到 100 后，可通过聊天页的誓约入口开始仪式；完成后可重温。
- **清除聊天**：在设置中选择“清除聊天记录”。此操作与清除长期记忆不同。
- **退出程序**：关闭窗口后程序仍驻留托盘；从托盘菜单选择“退出”才会完整停止。

云端音色需要当前账号具有使用权限；若音色不可用，请配置账号有权使用的音色。

## 如何移除

1. 从托盘菜单选择“退出”，确保客户端已停止。
2. 删除整个项目目录，即可移除项目内的 Python、语音环境、模型、缓存、设置和聊天数据。
3. 如需同时删除保存的 API Key，在资源管理器地址栏输入 `%LOCALAPPDATA%\Ronova`，删除其中的 `client-models.bin`；若该文件不存在，则无需处理。
4. 如果曾在包含中文等字符的路径运行，程序可能为部分语音资源生成项目外缓存。需要彻底清理时，再检查并删除 `%TEMP%\Ronova\native-resource-cache` 和 `%PUBLIC%\Ronova\native-resource-cache`；目录不存在时无需处理。

删除项目不会卸载系统显卡驱动或系统 Visual C++ 运行库。
